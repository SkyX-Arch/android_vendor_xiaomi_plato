# Contributing

Thanks for your interest in contributing to this project.

This repository is focused on maintaining proprietary vendor blobs for Xiaomi 12T (plato).

---

## 📌 Scope

Contributions are welcome in the following areas:

- Updating blobs from newer official Xiaomi firmware
- Fixing extraction or packaging issues
- Improving build compatibility with AOSP-based ROMs
- Documentation improvements

---

## ⚠️ Important rules

- Do NOT modify proprietary binaries
- Do NOT re-engineer or alter vendor files
- Only clean extraction and packaging changes are allowed
- Keep compatibility with Xiaomi 12T (plato)

---

## 🧩 How to contribute

1. Fork the repository
2. Make changes in a separate branch
3. Ensure changes are based on official Xiaomi firmware
4. Test build compatibility if possible
5. Submit a pull request with a clear description

---

## 📦 Source requirement

All blobs must come from official Xiaomi firmware packages.

No third-party or modified binaries are accepted.

---

## 🚧 Notes

- This is a development-focused repository
- Stability and compatibility are the main priorities
